# Contract: emitted agent YAML file

Every save (create or edit) regenerates `agents/<name>.yaml` in full from the schema (clarification Q2). The file must load with `yaml.safe_load` into exactly the mapping the orchestrator expects (`orchestrator/definitions.py` + `factory.py`), and must read well by hand.

## Layout rules

1. **Header**: three comment lines — the harness's one-line description, `# Generated by the agentbox UI — edits made here are replaced on the next save from the UI.`, and `# agentbox-schema: <N>` (the schema version the file was written with; see research R12). Files without the stamp are read as version 0.
2. **Sections** in this fixed order, each introduced by a blank line and `# --- <Section label> ---`, and each omitted entirely if none of its fields apply to the harness or have a value: Identity, Model, Prompt & output, Workspace, Execution, Scheduling, Container resources, Environment, Unmanaged.
   - **Unmanaged** holds any key present in the loaded file that the schema does not define, emitted verbatim (`yaml.safe_dump` of that sub-mapping) under `# --- Unmanaged (not edited by the UI) ---`. The UI never drops a key it does not understand.
3. **Field lines** in schema order within the section: `<key>: <value>  # <help text>`, values serialised with PyYAML flow style so quoting is always valid (`"30 2 * * *"`, `"claude-opus-4-8[1m]"`, `""`).
4. **Omission**: a field that is not applicable to the harness is never written. A field that is applicable but unset is written as a commented-out line `#<key>:  # <help text>` so the file documents what can be configured (matches the existing templates' convention). "Unset" means `null`, an empty list, or an empty map; an empty string is a real value only for `schedule` (manual-only) and is otherwise treated as unset. `name`, `enabled`, `harness`, `prompt_file`, `output_dir`, `network`, and `schedule` are always written.
   - **Writes are atomic** (temp file in the same directory, then rename) and the file is UTF-8 with LF line endings and one trailing newline (FR-004a).
5. **Lists** (`allowed_tools`, `disallowed_tools`): `key:  # help` followed by `  - item` lines; an empty list is treated as unset.
6. **Maps** (`env`): `env:  # help` followed by `  KEY: value` lines, values PyYAML-quoted (`${GITHUB_TOKEN}` stays unquoted since it is a valid plain scalar; values with `:` or `#` are quoted). Empty map → commented `#env:`.
7. **Comments** are the exact `help` strings from `ui/schema.py` — the same text shown in the form. Only ASCII em dashes/quotes already present in help text are allowed; no other formatting.
8. **Line width**: help text is not wrapped; long values are not folded.

## Example (harness `pi`)

```yaml
# Runs pi, a minimal coding agent with a full tool loop, against the LiteLLM proxy.
# Generated by the agentbox UI — edits made here are replaced on the next save from the UI.
# agentbox-schema: 1

# --- Identity ---
name: repo-librarian-pi-kimi  # Unique kebab-case identifier. Becomes the Dagster job agent_<name> (hyphens become underscores).
enabled: true  # Disabled agents are skipped when Dagster loads the workspace.
harness: pi  # Which runtime runs this agent; determines the available fields and models.

# --- Model ---
model: kimi  # Model the harness talks to. pi: a LiteLLM alias from litellm/config.yaml, or provider/model.
effort: max  # Reasoning/thinking effort level. pi: off, minimal, low, medium, high, xhigh, or max.

# --- Prompt & output ---
prompt_file: repo-librarian.md  # File in prompts/ read at launch and given to the agent as its prompt.
output_dir: /data/outputs/repo-librarian/pi-kimi  # Host directory mounted at /output; every run writes its result files here.
#append_system_prompt:  # Extra text appended to the system prompt.

# --- Workspace ---
workspace: /data/workspaces/repo-librarian/pi-kimi  # Host directory mounted at /workspace; scratch space for the run.
wipe_workspace: true  # Empty the workspace before every run so each run starts clean.

# --- Execution ---
timeout_seconds: 1800  # The run is killed after this many seconds.
allowed_tools:  # Tool allowlist. pi: any of read, write, edit, bash, grep, find, ls.
  - read
  - write
  - bash

# --- Scheduling ---
schedule: ""  # Cron expression for automatic runs; leave empty for manual-only.

# --- Container resources ---
network: agentnet  # Docker network: agentnet-isolated (LiteLLM only, no internet), agentnet (LiteLLM + internet), bridge (full internet — needed by claude-code and codex). Default depends on harness.
memory: 1g  # Container memory limit (e.g. 512m, 1g). Default 1g.
cpus: 1.5  # Container CPU limit (e.g. 1.5). Default 1.5.

# --- Environment ---
env:  # Environment variables for the container. ${NAME} forwards the host variable by name without exposing its value.
  GITHUB_TOKEN: ${GITHUB_TOKEN}
  GITHUB_USER: leeclemmer
```

## Round-trip guarantees (tested)

- `safe_load(emit(cfg)) == cfg` for every applicable, non-null field, unmanaged keys included.
- Emitting the parsed form of each existing `agents/*.yaml` (templates included) produces a file that `factory.py` treats identically: same keys, same values.
- Emitting twice yields byte-identical output (deterministic ordering).
- Every existing `agents/*.yaml` loads through the full migration chain (`MIGRATIONS` in `schema.py`) and validates; a file stamped with a newer schema version than the running UI is refused with a clear error rather than migrated backwards.
