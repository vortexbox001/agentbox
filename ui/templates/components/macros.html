{# Shared component macros — spec 009 US2 (contracts/component-macros.md). One macro per design-system component listed in ui/design-system/_ds_manifest.json (Tab is part of tabs → thirteen macros). Each macro emits markup + the design-system ROOT class only (no event props); existing behavioural JS wires interaction. Pages compose these macros so control styling lives in one place (FR-006). Styling comes entirely from the design-system tokens via static/app.css — no literal colour, pixel value, or typeface name lives here (test_conformance.py, FR-022). The `ax-` class prefix is the app namespace behavioural JS and tests key off (FR-025); only the retired design tokens were dropped, never the class names. Every macro takes an optional `attrs` dict of extra HTML attributes (id, data-*, title, aria-*, …) rendered with the built-in `xmlattr` filter (values are escaped; a None value is dropped).
