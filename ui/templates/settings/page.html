Run governors

Bound automated trigger chains. A run that would exceed a limit is refused, logged, and skipped without consuming a slot; manual runs bypass both. The orchestrator reads these on its next reload.

Max runs per hour {{ ui.text_input(name="max_runs_per_hour", id="ax-governors-runs", type="number", value=governors.max_runs_per_hour, attrs={"min": "1"}) }} Cap on automated runs per rolling 60-minute window. Manual runs bypass. Default 12.
Max chain depth {{ ui.text_input(name="max_chain_depth", id="ax-governors-depth", type="number", value=governors.max_chain_depth, attrs={"min": "1"}) }} Cap on how deep an automated chain of triggers may go. Manual runs bypass. Default 5.
