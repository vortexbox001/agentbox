# AgentBox App UI Kit

Interactive recreation of the AgentBox application interface. Demonstrates the full app shell including:

- **Sidebar navigation** — 240px collapsible sidebar matching Dagster's layout (68px collapsed)
- **Agent list view** — stat cards, tabbed filtering, data table with status badges
- **Navigation** — clickable nav items with active state highlighting

## Files
- `index.html` — Main entry point, renders the full app
- `Sidebar.jsx` — Left navigation component with nav groups
- `AgentsPage.jsx` — Agent list page with stats, tabs, and table

## Usage
Open `index.html` in a browser. Click sidebar items to navigate. Click "Collapse" to toggle the sidebar width.
