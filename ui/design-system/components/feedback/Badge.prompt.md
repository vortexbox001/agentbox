Badge is a small status indicator for runs, agents, and categories.

```jsx
<Badge label="running" intent="running" />
<Badge label="success" intent="success" />
<Badge label="error" intent="error" />
<Badge label="scheduled" intent="scheduled" />
```

**Intents:** running (teal), success (green), error (red), warning (yellow), queued (gray), scheduled (lime), default (gray), primary (teal).
